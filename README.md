# Exploratory Data Analysis (EDA) Project

Data Analysis

## Objective
The objective of this project is to perform Exploratory Data Analysis (EDA) on the Netflix dataset to uncover trends, patterns, and insights using statistical analysis and data visualization techniques.


## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Features
- Data Cleaning
- Missing Value Handling
- Statistical Summary
- Trend Analysis
- Correlation Analysis
- Data Visualization


## Visualizations Included
- Movies vs TV Shows Count
- Top Content Producing Countries
- Content Release Trend
- Ratings Distribution
- Correlation Heatmap


## Insights
- Movies are more common than TV Shows on Netflix
- United States produces the highest amount of content
- Content releases increased significantly after 2015
- TV-MA is the most common content rating

This project helped develop analytical thinking, data exploration skills, and visualization techniques using real-world datasets.
